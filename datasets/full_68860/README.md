# Full 68,860-record dataset index

The complete anime-derived audio collection is verified locally but restricted from redistribution. This directory publishes sanitized pseudo-label metadata and a path-free checksum index; it does not contain or link to WAV/ZIP payloads.

- `pseudolabel_manifest_sanitized.csv`: pseudo-label and quality metadata.
- `audio_checksums_sanitized.csv`: 68,860 stable record IDs, exact WAV SHA-256 values, sizes, archive-part identities, inherited labels, and status fields.

See [`docs/PAPER_DATASET_EVIDENCE.md`](../../docs/PAPER_DATASET_EVIDENCE.md) for lineage, limitations, and publication status.
